### Type scale (verified)

Every size is one fluid function, generated by this helper (`qE(min,max)`):

```js
function o(e,t,n=375,a=1800){let o=t-e;return "min(MAXpx, max(MINpx, calc(MINpx + DELTA * ((min(100vw, 100vh * 1.7777) - 375px) / 1425))))"}
```

i.e. the viewport width is clamped to a 16:9 box (`min(100vw, 100vh*16/9)`) so tall
narrow windows do not get oversize type, then linear between 375 and 1800px.

### Motion (verified)

Libraries: GSAP 3.15.0 (`version="3.15.0"` x8), Lenis (react wrapper `ReactLenis root`), three.js r183, @react-three/fiber, @react-three/rapier, CustomEase.

Eases registered once in the layout, then used by name everywhere:

```js
l.Ay.defaults({ease:"none"});
CustomEase.create("in","0.815, 0.005, 0.810, 0.195");
CustomEase.create("out","0.200, 0.715, 0.205, 0.990");
CustomEase.create("inOut","0.835, 0.120, 0.225, 0.770");
CustomEase.create("outFast","0, 0, 0, 1");
gsap.ticker.lagSmoothing(0); gsap.ticker.remove(gsap.updateRoot);
lenis.add(e=>{gsap.updateRoot(e/1e3)},{priority:0})   // Lenis drives the GSAP clock
```

CSS uses the same two curves: `cubic-bezier(0, 0, 0, 1)` x48 (hover/UI),
`cubic-bezier(0.200,0.715,0.205,0.990)` x32, `cubic-bezier(0.835,0.120,0.225,0.770)` x14.
Durations in CSS: 0.2s (buttons), 0.5s (colour/opacity), 0.6s (mask wipe), 0.8s
(reveal), 1s (hairline grow with 0.2/0.3/0.4s stagger), 2s (header fade).
GSAP durations: `.5` x8, `1.5` x5, `.75` x4, `.4`, `.66`, `2`.

Lenis: `<ReactLenis root>` with default options (no custom `lerp`/`duration` passed;
library default `lerp:.1`, `smoothWheel:true`, `wheelMultiplier:1`, `syncTouch:false`).
Blog, `/mcp` and co-create routes opt out. ScrollTrigger is mounted only off-blog.

Split-text reveal (the h1 and every h2), GSAP SplitText:


An SR-only copy of the text is kept (`clip:rect(0 0 0 0);clip-path:inset(50%)`), the

Optional `$highlightWords` dims `.word{opacity:.3}` and lights the first N.


Gradient border: a 4-step `gsap.timeline({repeat:-1})` tweening background positions, `duration:1,ease:"linear"`.

Hero (3D keychain): R3F canvas, `PerspectiveCamera fov:35 far:500` at `[0,-4,10]`,

plus pointer repulsion. There is no "ball pushes letters" effect on butter.

## Five things to copy

1. The fluid size function `min(MAX, max(MIN, calc(MIN + DELTA * ((min(100vw,100vh*16/9) - 375px)/1425))))` for type, radii and padding; one formula, no breakpoints in the type scale.
2. Register four named eases (`in`, `out`, `inOut`, `outFast` above) once and use them in both CSS vars and GSAP; drive `gsap.updateRoot` from Lenis's raf so scroll and tweens share one clock.
3. The statement FLIP: render each tile once, keep two sets of invisible placeholders (inline `1em` spans in the heading, squares in a row), measure both with `getBoundingClientRect`, tween `scale/x/y` for 1.5s `power2.inOut` with a 0.75s wobble and a per-tile stagger that flips with scroll direction.
4. SplitText with an SR-only twin: `yPercent:60` + opacity, `ease:"outFast"`, stagger `i*0.05` for words with the last three words slowed 1.5x; masks via `.line-mask{padding:.1em 0;margin:-.2em 0}`.
5. Nav as a flat `#EDEDED` pill (`border-radius:1.6rem`, no blur), buttons at `--radius:1.6rem;height:5rem` with the stacked five-colour glow on hover and a 2s `hue-rotate` loop; light section ending in `border-radius:0 0 6rem 6rem;margin-bottom:-6rem` over the dark one.
